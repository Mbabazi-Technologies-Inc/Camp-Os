Mill Stream merch logos

Two versions for sweatshirts, shirts, water bottles and stickers. Every file is a vector SVG with the lettering converted to shapes, so printers don't need any fonts. There's a 3000 px transparent PNG next to each SVG for anyone who asks for an image.

Full colour suits embroidery, stickers and digital printing. One colour is a single screen-print ink, with the details cut out so the garment shows through: navy on light garments, white on dark ones.
